# StudyFlow 5.0 — React + Gemini API

고등학생을 위한 시험 일정 최적화 및 AI 분석 웹앱. 학교 컴퓨터에서는 배포된 URL만 열면 됩니다.

## 로컬 실행

```bash
npm install
npm run dev
npm test
npm run build
```

## 실제 AI 분석 배포

1. GitHub 저장소에 프로젝트 폴더의 파일을 업로드합니다.
2. Vercel에서 저장소를 가져옵니다. 프레임워크는 Vite, 빌드 명령어는 `npm run build`, 출력 폴더는 `dist`입니다.
3. Vercel 프로젝트 환경 변수에 `GEMINI_API_KEY`를 등록합니다. **API 키를 React 소스코드나 GitHub에 올리지 마세요.**
4. 다시 배포하고 `/api/analyze`를 통해 실제 Gemini 응답을 확인합니다. API 키 없이도 일정 최적화는 작동하지만 AI 호출은 실패 메시지가 뜹니다.
5. 학교 컴퓨터의 브라우저에서 배포 URL을 열어 시연합니다. 학교망에서 Vercel이 차단되어 있는지 미리 확인하세요.

## 3분 시연 순서

1. `시연 데이터 초기화`를 눌러 예시 과목 4개와 7일 계획을 불러옵니다.
2. 대시보드에서 총 공부량과 7일 배정 시간을 확인합니다.
3. `수학 80분 미완료` 버튼으로 변경 전후 배정 시간을 비교합니다.
4. `학습 기록`에서 실제 공부한 시간을 입력해 계획이 다시 계산되는 모습을 보여줍니다.
5. `AI 인사이트`에서 실제 Gemini 분석 버튼을 눌러 결과를 보여줍니다.

## 구현 범위와 주의

- 일정 최적화는 15분 단위 휴리스틱이며 수학적으로 전역 최적을 보장하지 않습니다.
- Gemini는 최적화 결과를 해석하며 실제 계획 계산을 대신하지 않습니다.
- 저장은 브라우저 localStorage에만 됩니다. 컴퓨터나 브라우저가 달라지면 기록이 공유되지 않습니다.
- API 호출 실패 시 결과를 조작하거나 가짜 AI 답변을 보여주지 않습니다.
- 시연 전 배포 주소와 API 응답을 직접 테스트하세요.
